# Social Media Campaign Performance Analysis

## Project Overview
This project analyzes social media campaign performance using SQL and Power BI to understand how businesses can improve audience engagement, ad performance, and conversion outcomes through data-driven decision making.

The project follows an end-to-end analytics workflow:
- SQL for business problem solving and analysis
- Power BI for dashboard development and visualization
- DAX for KPI calculations and interactive insights

---

# Main Business Problem

How can a company improve social media ad campaign performance and user engagement?

---

# Tools & Technologies Used

- SQL
- Power BI
- DAX
- Excel / CSV Dataset

---

# Project Workflow

## 1. SQL Analysis
Business problems were solved using SQL across 4 major areas:

- Platform Performance Analysis
- Audience Behavior Analysis
- Ad Strategy Analysis
- Engagement Trend Analysis

The SQL analysis focused on:
- Click-through rate (CTR)
- Conversion performance
- Audience engagement
- Platform comparison
- Device behavior
- Ad effectiveness
- User interaction trends

---

## 2. Power BI Dashboard
An interactive 5-page Power BI dashboard was created based on the SQL analysis and business insights.

Dashboard Pages:
1. Overview
2. Platform Performance Analysis
3. Audience Behavior Analysis
4. Engagement Trend Analysis
5. Business Insights & Recommendations

---

# SQL Problems Solved

- Which platform generates the highest CTR and conversion rate?
- What is the engagement pattern across different age groups?
- Which ad type (image, video, carousel) performs best?
- How does engagement vary by day of week?
- Which interests drive the most clicks?
- How does device type (mobile/desktop/tablet) impact engagement?

# Dashboard Highlights

## Overview

---

## Platform Performance
- Instagram achieved the highest engagement and CTR
- Instagram CTR: 55.67%
- Instagram Conversion Rate: 10.65%

---

## Audience Behavior
- Most engaged age group: 25–34
- Most engaged gender: Female
- Top audience interest: Tech

---

## Engagement Trends
- Wednesday showed highest engagement
- Mobile users interacted more with campaigns
- Instagram performed better across devices

---

## Business Recommendations
- Focus more campaign budget on Instagram
- Target users aged 25–34
- Prioritize image and video advertisements
- Optimize mobile-first campaigns
- Use interest-based audience targeting

# What I Learned

- CTR and Conversion Rate tell different stories — CTR measures interest while Conversion Rate measures action
- Instagram drives higher engagement than Facebook for this audience
- Wednesdays and Sundays showed the strongest audience engagement trends
- Image advertisements generated stronger engagement performance than video ads
- Mobile users engage more but convert less, indicating opportunities for further campaign optimization
